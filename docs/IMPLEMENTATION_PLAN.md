# Implementation plan — 2026-10-16

## Scope and acceptance
Build a local, offline-capable Python/Streamlit research beta, with independent analytical modules. Deployment is optional in the supplied specification and is deferred. A successful release requires real historical ingestion, strict pre-date features, temporal predictive evaluation, three static tactical alternatives, an executable decision tree, reproducible Monte Carlo, one/two-way sensitivity, uncertainty-aware conclusions, research exports, and passing mathematical/integration/UI checks.

1. Inspect materials; acquire a frozen public community archive with provenance and local-only data storage.
2. Validate canonical entities and round-level counts; log exclusions; generate profiles and chronological features without current-career attributes.
3. Fit symmetric regularized logistic regression on eligible earlier bouts. Select regularization with temporal validation and evaluate an untouched test block; retain an exploratory mode if performance is weak.
4. Implement explicit bounded tactical effects, response assumptions, expected utilities, shared-draw simulation, regret, sensitivity and switching thresholds.
5. Connect an English Streamlit UI, CSV/JSON/HTML exports, reproducibility script and notebook; verify the end-to-end journey and document measured results.

## Risks and conservative choices
- UFCStats is not an official API. Use published archive CSVs, do not scrape UFCStats. Record upstream GPL-3.0 and unresolved original-source rights; keep raw and processed data out of Git.
- Public observations do not identify tactical intervention effects. Presets start neutral; illustrative assumptions must be deliberately selected and remain labeled.
- Exclude draws, no-contests, disqualifications and unsupported formats from binary forecasting; preserve exclusion logs. Never encode nonwins as automatic defeats.
- Fight dates have day resolution: exclude the entire target date. Metadata available only as current snapshots must not be pre-fight predictors.
- Sparse histories, division mismatch, unvalidated probabilities and uncertain tactical feasibility must be visible.
- Baseline bootstrap uncertainty is conditional on the fitted feature design and training data. It is not a complete account of forecast uncertainty.
